Tips for best accuracy

  • Plain background, front lighting on hand, avoid shadows.
  • Keep hand centered, ~30–50cm from camera, palm mostly forward.
  • Hold steady 1–2 seconds; avoid motion blur.
  • Currently best: A, B, C, D, L, V, W, O, F, Y, I + words hello, thank, please, yes, no, help, love.
  • Click any detected sign to hear it and see the 3D avatar in Learn.
  • Demo mode auto-simulates if MediaPipe fails to load (offline).

Privacy & How it works

  • On-device: Hand landmarks are detected locally with MediaPipe Hands; no video is uploaded.
  • Template matching: Finger curls (thumb–pinky) are compared to templates derived from SIGN_DATA (the same data that drives the 3D avatar). Confidence = 1 − distance/√5.
  • Stability: Requires ~8 consistent frames + 60% confidence to confirm, preventing flicker.
  • Fallback: If camera/MediaPipe unavailable, a demo loop simulates detections so the UI remains testable.

    How it works

    • Summarizer: TF-based extractive algorithm — scores sentences by keyword frequency, position and length, then picks the most representative ones in original order. No AI API, no data leaves your browser.
    • Flashcards: Cloze deletions + “What does the doc say about X?” questions auto-built from summary sentences. Flip, shuffle, export to TXT/CSV for Anki/Quizlet.
    • Audible: Uses the Web Speech API (speechSynthesis). Same engine as Speech Mode. For a permanent MP3, use your OS screen reader's “Save audio” or re-record; browsers cannot directly export synthesized speech to file.
