    How it works

    • Summarizer: TF-based extractive algorithm — scores sentences by keyword frequency, position and length, then picks the most representative ones in original order. No AI API, no data leaves your browser.
    • Flashcards: Cloze deletions + “What does the doc say about X?” questions auto-built from summary sentences. Flip, shuffle, export to TXT/CSV for Anki/Quizlet.
    • Audible: Uses the Web Speech API (speechSynthesis). Same engine as Speech Mode. For a permanent MP3, use your OS screen reader's “Save audio” or re-record; browsers cannot directly export synthesized speech to file.
